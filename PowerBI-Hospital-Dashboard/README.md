# Hospital Emergency Room Dashboard

## Overview

This project is an interactive **Hospital Emergency Room Dashboard** built in Microsoft Power BI. It provides insights into patient volume, waiting times, admission status, referrals, patient demographics, and emergency room activity through interactive visualizations and KPI cards.

## Tools & Features

- Microsoft Power BI
- Power Query
- DAX
- Interactive Slicers
- KPI Cards
- Charts & Tables
- Page Navigation
- Reset Filters
- Last Refresh Indicator

## Dashboard Highlights

- Total Number of Patients
- Average Wait Time
- Patient Satisfaction Score
- Number of Patients Referred
- Patient Admission Status
- Percentage of Patients Seen Within 30 Minutes
- Patient Volume by Day & Hour
- Patients by Age Group
- Patients by Gender
- Patients by Race
- Patients by Department Referral
- Detailed Patient-Level Information

## Dashboard Pages

### Monthly View

Provides a monthly analysis of Emergency Room activity using Year and Month filters.

### Consolidated View

Provides an overall analysis of Emergency Room performance across the selected date range.

### Patient Details

Provides detailed patient-level information including patient demographics, admission date, wait time, department referral, and admission status.
